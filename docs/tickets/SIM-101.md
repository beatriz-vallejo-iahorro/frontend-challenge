# SIM-101 · La cuota sale `NaN` con TIN 0 % y redondea mal

**Tipo:** Error · **Prioridad:** Alta · **Reportado por:** Producto

## Descripción
Hemos visto dos problemas en la cuota mensual del simulador.

### 1. TIN 0 %
Algunas promociones de vivienda ofrecen financiación al 0 %, y con TIN 0 el simulador muestra `NaN €`.

**Pasos:**
1. Precio de la vivienda: 180000
2. Ahorros aportados: 30000
3. Plazo: 25 años
4. TIN: 0
5. Pulsar "Calcular"

**Resultado actual:** `Cuota mensual: NaN €`
**Resultado esperado:** `Cuota mensual: 500,00 €` (150.000 € en 300 cuotas)

### 2. Redondeo
La cuota sale a veces un céntimo por debajo de lo que dan los bancos.

**Pasos:** precio 300000, ahorros 50000, plazo 30 años, TIN 2,25.
**Resultado esperado:** `955,62 €`

Hay un test en `skip` que lo reproduce.

## Criterios de aceptación
- [ ] Con TIN 0 la cuota es el capital dividido entre el número de cuotas.
- [ ] La cuota se redondea al céntimo más cercano.
- [ ] Hay tests que cubren ambos casos.
