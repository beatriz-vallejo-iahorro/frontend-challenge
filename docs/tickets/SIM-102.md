# SIM-102 · Comparar hipoteca fija y variable

**Tipo:** Historia · **Prioridad:** Alta · **Reportado por:** Producto

## Historia
Como persona que está decidiendo qué hipoteca contratar, quiero ver a la vez la cuota de una hipoteca fija y la de una variable para poder compararlas.

## Criterios de aceptación
1. Además del TIN de la hipoteca fija, se puede introducir el diferencial de la hipoteca variable.
2. La cuota de la variable se calcula con el Euríbor actual más el diferencial.
3. Las dos cuotas se calculan con la TAE de cada oferta, para que la comparación sea justa.
4. Se muestran las dos cuotas y la diferencia mensual entre ellas.
5. Si la financiación supera el 80 % del precio de la vivienda, se muestra el aviso: "La mayoría de los bancos financian como máximo el 80 % del precio de la vivienda."
6. Los importes se formatean con el composable `useCurrency` de `@iahorro/utils`, como en el resto de la web.

## Notas de producto
- Para simplificar, la variable se calcula como si el tipo se mantuviera durante todo el plazo. Sabemos que en la realidad se revisa.
- No hace falta guardar nada ni llamar a ningún backend propio.
